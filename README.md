## 🌟 Sobre o Projeto

O **Free Todo List** é uma aplicação de gerenciamento de tarefas focada em simplicidade e eficiência. O projeto foi desenvolvido com foco em manipulação de DOM e persistência de dados no lado do cliente.

### 🚀 Funcionalidades Principais

* **Criação de Tarefas:** Adicione novos itens rapidamente através de uma interface intuitiva.
* **Edição Flexível:** Altere o texto de tarefas já criadas sem precisar excluí-las.
* **Marcação de Conclusão:** Controle visual do que já foi feito com feedback imediato.
* **Exclusão de Tarefas:** Remova itens da lista com apenas dois cliques.
* **Persistência de Dados:** Integração com `localStorage` para manter suas tarefas salvas mesmo após fechar o navegador ou dar F5.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com "tecnologias puras", demonstrando domínio sobre a base do desenvolvimento web:

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Layout responsivo (Mobile-first) e variáveis nativas.
* **Vanilla JavaScript:** Lógica de estado, manipulação cirúrgica do DOM e persistência em memória local.

## 🏁 Como Executar o Projeto

Siga estes passos simples para rodar o projeto localmente no seu sistema (Linux/Mac/Windows).

### Pré-requisitos

Você só precisa de um navegador web moderno (Chrome, Firefox, Brave, etc).

### Instalação

1.  **Clone o Repositório:**
    ```bash
    git clone https://github.com/rodrigo1608/free-todo-list.git
    ```

2.  **Acesse o Diretório do Projeto:**
    ```bash
    cd free-todo-list
    ```

3.  **Abra o Aplicativo:**
    Basta abrir o arquivo `index.html` no seu navegador ou utilizar a extensão *Live Server* do VS Code.
